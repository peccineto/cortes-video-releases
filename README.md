# Cortes de Vídeo — instaladores

App para Windows que prepara vídeos para envio: corta silêncios, acelera, comprime, gera capítulos com título
e permite revisar os cortes pelo texto. Aqui ficam só os instaladores; as atualizações chegam sozinhas no app.

## Instalar

1. Baixe o `CortesDeVideo-Setup-<versão>.exe` da **[versão mais recente](https://github.com/peccineto/cortes-video-releases/releases/latest)**.
2. Dê dois cliques. Se aparecer **"O Windows protegeu o computador"**, clique em **Mais informações → Executar
   assim mesmo** (o instalador não tem assinatura digital paga).
3. Na primeira abertura o app prepara o que precisa (uns 4 GB, só uma vez, precisa de internet).

Depois disso, novas versões são baixadas e instaladas automaticamente (ou em **Ajuda → Procurar atualizações**).
